This is a **sample post**. It shows what a blog post looks like on this site, and it is hidden from search engines until you replace it.

## Write in plain text

Open the dashboard, choose **Blog posts**, and write in the editor. Headings, lists, links and code all work:

- Add a cover image and tags
- Set a future date to schedule a post
- Tick *Draft* to keep it private while you write

```bash
git push origin main
```

> Short posts that you actually publish beat long posts that stay in drafts.
